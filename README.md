### React + TypeScript + Vite + Tailwind

Iteration of e-commerce app to integrate with Stripe Payment.

Currently in development.

## Tech Stack

- React 19
- TypeScript
- Tailwind CSS
- Tailind Variants
- Hono
- Stripe

---

#### To run this project locally:

1. Click Fork on GitHub

2. Clone your fork:

```
git clone https://github.com/rhw-repo/react-store.git
```

3. Navigate into the app directory (the app lives in `client/`, not at the repo root):

```
cd react-store/client
```

4. Install dependencies:

```
pnpm install
```

5. Start the dev server

```
pnpm run dev
```
